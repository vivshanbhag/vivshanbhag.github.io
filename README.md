# Vivek Shanbhag — professional website

Static résumé and portfolio site for Cloudflare Pages, deployed from this GitHub repository. Cloudflare Pages provides a free `*.pages.dev` address; the repository remains the source of truth.

## Files

- `index.html` — accessible, search-readable profile, experience, project, and résumé content
- `styles.css` — responsive Carbon + Teal theme, including print styles
- `script.js` — mobile navigation, print-to-PDF, and current-year label

The OPS On-Call Agent is described only at a high level because its implementation is internal. Architecture studies are identified as design work. Use the “Print / Save résumé” control in a browser to print or save the page as PDF.
