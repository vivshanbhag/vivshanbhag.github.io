# Vivek Shanbhag — professional website

Static résumé and portfolio site for Cloudflare Pages, deployed from this GitHub repository. Cloudflare Pages provides a free *.pages.dev address; the repository remains the source of truth.

## Files

- index.html — accessible, search-readable profile, experience, project, résumé, and social-preview metadata
- styles.css — responsive Carbon + Teal themes, scroll effects, reduced-motion support, and print styles
- script.js — mobile navigation, saved light/dark preference, scroll progress, parallax/reveal effects, and current-year label
- Vivek-Shanbhag-Resume.pdf — standalone, ATS-readable résumé available from the hero download button
- social-preview.png — 1200 × 630 LinkedIn/Open Graph share image
- favicon.svg — abstract Carbon Teal site icon
- highmark-logo.jpg — Highmark mark from the company LinkedIn page you shared
- apple-touch-icon.png — square icon for mobile bookmarks

The independent Incident Triage Agent open-source reference project links to its GitHub repository and HLD/LLD documents. Employer work remains described at a high level. Company logos are local files where available; some favicon images are still loaded from Google because logo download requests were blocked in this environment.
