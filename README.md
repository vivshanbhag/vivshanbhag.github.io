# Vivek Shanbhag — Professional Website

Personal résumé and portfolio website for sharing Vivek’s professional background, engineering experience, technical skills, education, and selected work.

**Live website:** [vivshanbhag.github.io](https://vivshanbhag.github.io/)

## Website sections

- **Home and About** — introduces Vivek, his current role, engineering background, and professional interests.
- **AI & Agentic Work** — features the Incident Triage Agent, an independent open-source reference project, with links to its repository and high-level and low-level design documents.
- **Career** — presents a chronological work history with role descriptions, selected outcomes, and company marks.
- **Technical Toolkit** — groups skills across software engineering, systems and cloud engineering, AI and machine learning, and data engineering and analytics.
- **Education & Recognition** — summarizes academic credentials, awards, and certifications.
- **Let’s Connect** — provides LinkedIn and email contact options. The email control copies the address to the clipboard and confirms when it succeeds.
- **Footer** — links to GitHub and LinkedIn and displays the current year. A floating control lets visitors return to the top of the page.

## Theme and responsive behavior

By default, the site follows the visitor’s operating-system light or dark preference. The sun/moon control switches themes manually, and the selected theme is remembered for later visits. Layouts adapt for mobile screens, and motion effects respect the reduced-motion accessibility setting.

## Résumé

The **Download résumé** link in the home section downloads the standalone PDF. The page also includes print-specific styling, so it can be printed or saved as a PDF using the browser’s print command.

## Built with

Plain HTML, CSS, and JavaScript. No framework or build step is required.

## Main files

- `index.html` — page content, navigation, and sharing metadata
- `styles.css` — visual styles, themes, responsive layout, and print layout
- `script.js` — theme selection, mobile navigation, scroll effects, and dynamic footer year
- `Vivek-Shanbhag-Resume.pdf` — downloadable résumé
- `social-preview.png`, `favicon.svg`, and `apple-touch-icon.png` — sharing and browser icon assets
